## 一、技术选型：Hugo + 双站部署

本站用 Hugo 0.167.0 构建，主题是自写的极简中文主题。一次构建，同时部署到两个地方：

- GitHub Pages：`hkid0.github.io`
- Cloudflare Pages：`hkid0.pages.dev`

靠 `relativeURLs=true`，同一份构建产物双站通用。发布流程很简单：本地写好 Markdown，运行 `push.py`（走 GitHub Contents API）推送到仓库，双站自动构建上线。

## 二、改名史：从 LXCHK 到 hkid0

一天之内改了三轮：

- GitHub 用户名：LXCHK → hk-id → hkid0
- 站点品牌：cnid → hk-id → 香港身份 HKID 之旅 → 香港身份 HKID 从 0 出发

`hkid` 这个短名字在 GitHub 和 Cloudflare 都被占了，`hkid0` 因祸得福——多出来的 0 正好呼应"从 0 出发"，反而成了点睛之笔。

Cloudflare 那边有个坑：Pages 项目改名不会更换 `pages.dev` 子域名，只能删除重建。构建配置（`hugo --minify`、HUGO_VERSION=0.167.0）原样迁移，一次成功。

## 三、Favicon：十四版才定稿

第一版是红底圆角徽章加白洋紫荆和黄五角星，被否——观感上"政治不正确"。之后试了多版 SVG 手绘的两旗叠放方案：星的大小、花瓣的形状、旗面的波浪，逐版被否决。

最终方案：直接用一张两旗飘扬的合成图，白背景转透明，压缩到 256px（91KB），base64 内嵌进 SVG。页眉左上角同时放上这个 logo，点击回首页。

## 四、功能迭代

- **导航**：一开始是右侧抽屉菜单，后来改成只有小屏设备才折叠（下拉式，非抽屉），iPad 和桌面端直接显示全部链接。
- **深色模式**：跟随系统的 `prefers-color-scheme` 自动切换，另配了一套深色纸墨色板。
- **首页时间线**：最初把每篇文章的全文都堆在首页，后来改成只列各文章的二级标题，清爽多了。

## 五、工作流

素材（图片＋文字）发过来 → 整理成 Markdown → 脱敏（隐去姓名、学校、公司、档案号、电话等）→ 确认 → `push.py` 发布 → 双站自动同步。
